# S-P-500-Ranking-Dashboard
- Interactive S&P 500 stock ranking and forecasting platform leveraging machine learning and quantitative analysis.
- Processing and analysis of 80,000+ Bloomberg financial data points across 503 companies from 2005–2025.
- Comparative evaluation of AdaBoost, XGBoost, Random Forest, ANN, and Linear Regression models.
- Performance validation through out-of-sample backtesting, quintile spread analysis, and Spearman IC metrics.
- Interactive dashboards and visualizations enabling data-driven investment insights.
- To run the dashboard locally, install all dependencies listed in requirements.txt.
- Please watch the provided video demonstrating the final dashboard in action.
