# S-P-500-Ranking-Dashboard
- Developed an interactive S&P 500 stock ranking and forecasting dashboard using machine learning.
- Analyzed 80,000+ Bloomberg financial data points across 503 companies from 2005–2025.
- Evaluated multiple machine learning models to identify the highest-performing approach.
- Applied backtesting and quantitative metrics to validate model performance.
- Built interactive visualizations to support data-driven investment analysis.
- To run the dashboard locally, install all dependencies listed in requirements.txt.
- Please watch the provided video demonstrating the final dashboard in action.
